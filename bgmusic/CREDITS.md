# Games panel background music

Instrumental house / trance / acid jazz for the Games panel (`src/components/Games/GameMusic.tsx`).
All free to use without attribution - credited here anyway.

## Layout

- `house/`, `trance/`, `jazz/` - the subfolder is the genre shown in the player.
- Files are named `Artist - Title.opus`; the player shows "Title" over "Artist".
- Re-encoded from the originals to Opus 112kbps (`ffmpeg -c:a libopus -b:a 112k`) to keep the
  bundle small; the original files are in git history (before the Opus switch).
- Album art: drop a `.jpg` / `.png` / `.webp` with the same base name next to a track
  (`jazz/Alex Morgan - Acid Jazz Groove.jpg`) and the player shows it; otherwise it shows Gus in
  headphones.
